# DesktopTools

本项目原为自用，大多为vibe coding，有很多不足，现整理开源，若有bug，敬请见谅。

本项目提供了一套 Windows 桌面整理工具，包含三个独立的子模块：

- **桌面图标布局管理** – 保存与恢复桌面图标的位置布局
- **桌面壁纸修改工具** – 交互式裁剪、缩放、平移当前壁纸，以适应自定义桌面布局
- **毛玻璃分类窗口** – 在桌面上方创建半透明毛玻璃窗口，可任意移动、缩放、吸附网格，用于分类整理桌面内容

用户可以先使用“桌面壁纸修改工具”将壁纸调整到理想视图，然后创建多个毛玻璃窗口，将它们排列在桌面上，最后通过截屏保存最终的整理效果。  
同时，“桌面图标布局管理”工具可以在调整壁纸前后备份 / 恢复桌面图标位置。

---

## 子模块说明

| 模块           | 可执行文件        | 功能简介                                                     |
| -------------- | ----------------- | ------------------------------------------------------------ |
| 图标布局管理   | `RestoreDesktop`  | 保存当前桌面所有图标位置到 JSON 文件，并从 JSON 恢复位置     |
| 壁纸修改工具   | `ModifyDesktop`   | 全屏显示当前壁纸，支持鼠标拖拽移动、滚轮缩放（等比例 / 水平 / 垂直），可保存裁剪后的视图 |
| 毛玻璃分类窗口 | `ClassifyDesktop` | 创建多个半透明模糊窗口，实时跟随壁纸背景，支持网格吸附、键盘/鼠标调整、保存/恢复整体布局 |

详细使用方法见 `docs/` 目录下的对应文档。

> 注意：三个模块相互独立，可单独编译运行。

## 快速使用流程

1. **调整壁纸**  
   运行 `ModifyDesktop.exe` → 使用鼠标拖拽、滚轮（配合 Ctrl / Shift）调整壁纸的显示区域 → 按 `Ctrl+S` 保存裁剪后的图片（可选） → 按 `ESC` 退出。
2. **创建分类窗口**  
   运行 `ClassifyDesktop.exe` → 主控制窗口会显示，点击“新建毛玻璃窗口” → 拖动窗口标题栏移动，使用方向键微调位置（若启用网格吸附则自动对齐） → 可按 `Ctrl+S` 调整每个窗口的模糊强度、偏移、圆角、标题等。
3. **保存整体布局**  
   在毛玻璃主窗口中点击“保存布局”，可将所有毛玻璃窗口的位置、尺寸、样式保存到 `layout.ini`。下次启动可点击“读取布局”恢复。
4. **最终截图**  
   使用任意截图工具（如 `Win + Shift + S`）截取整个桌面，即可得到整理后的壁纸 + 分类窗口的最终效果图。
5. **替换壁纸**
6. **备份桌面图标**  
   运行 `RestoreDesktop.exe` → 点击“保存当前布局...” → 选择 JSON 文件保存图标位置。  
   在修改壁纸或整理后，可点击“恢复布局...”从 JSON 还原图标位置。

## 毛玻璃分类窗口 (ClassifyDesktop)

### 概述

创建一个主控制窗口，可生成多个半透明、模糊背景的子窗口，这些子窗口会实时捕获桌面壁纸对应区域并进行高斯模糊，模拟毛玻璃效果。用户可以将这些窗口作为“分类容器”，在桌面上任意摆放，用于整理图标、文件或作为视觉分区。

### 编译依赖

- Qt Widgets 模块
- 自定义高斯模糊算法（`fast_gaussian_blur_template.h`，高性能近似高斯模糊）
- Windows DwmApi（用于窗口样式）
- 链接库：`dwmapi`

### 主控制窗口功能

主窗口默认置顶，包含以下按钮：

| 按钮                           | 功能                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| **新建毛玻璃窗口**             | 创建一个新的毛玻璃子窗口，标题自动编号                       |
| **保存布局**                   | 将所有毛玻璃窗口的位置、尺寸、模糊参数、标题保存到 `layout.ini` |
| **读取布局**                   | 关闭当前所有窗口并从 `layout.ini` 重建之前保存的窗口         |
| **关闭所有窗口（不含主窗口）** | 关闭所有毛玻璃子窗口，可选择是否先保存布局                   |
| **启用网格吸附 (30px)**        | 所有窗口移动/微调后自动吸附到 30x30 的网格上                 |
| **退出程序**                   | 关闭所有窗口并退出                                           |

全局快捷键 **`Ctrl+H`**：隐藏 / 显示主控制窗口（仅在至少存在一个毛玻璃窗口时有效）。

### 毛玻璃子窗口功能

每个毛玻璃窗口具有以下特性：

- **标题栏**：可拖动移动窗口，标题文字可在设置中修改。
- **背景实时模糊**：窗口会截取自身所在位置下方的壁纸区域，使用快速高斯模糊算法（3 次 box blur）生成毛玻璃效果。
- **圆角边框**：可设置圆角半径。
- **键盘移动**：拖动标题栏后，可以使用方向键微调位置（步长 1 像素），释放鼠标或按键后自动吸附网格（如果启用）。
- **设置面板**：在子窗口上按 **`Ctrl+S`** 打开设置窗口，可调整：
  - 模糊强度（sigma，范围 3~100）
  - 壁纸偏移 X / Y（用于微调模糊背景的采样位置，解决因标题栏导致的内容偏移）
  - 圆角半径
  - 窗口标题
  - 窗口宽度 / 高度（范围 50~1000）
- **置顶行为**：所有毛玻璃窗口和主控制窗口均置顶于其他普通窗口之上，且相互之间不会遮挡（可以通过点击切换 Z 序）。

### 保存的布局内容

`layout.ini`（INI 格式）保存每个窗口的：

- `geometry`（窗口位置和大小，Qt 二进制格式）
- `sigma`（模糊强度）
- `offsetX`、`offsetY`（壁纸偏移）
- `cornerRadius`（圆角半径）
- `title`（窗口标题）

### 注意事项

- 毛玻璃窗口的背景模糊依赖于壁纸图像（启动时读取一次），如果壁纸发生变化，需要重新启动程序或手动刷新（最小化再还原）。
- 窗口数量过多时，每个窗口都会独立进行模糊计算，可能增加 CPU 负载。建议根据实际需求创建适量窗口（例如 6~8 个）。
- 网格吸附是全局设置，会影响所有窗口的行为。
- 主控制窗口关闭时，如果还有毛玻璃窗口存在，会最小化到托盘（实际上只是隐藏），不会退出程序。只有当所有子窗口都关闭后，关闭主窗口才会退出程序。

### 模糊算法

使用了 `fast_gaussian_blur_template.h` 中的高效近似高斯模糊：

- 通过多次 box blur 逼近高斯核（默认 3 次）
- 采用图像转置 + 水平 blur 的缓存优化策略
- 支持边界处理（mirror 模式）
- 对于 1920x1080 的图像，sigma=15 时每帧模糊耗时约 10~20ms（取决于 CPU）

### 已知限制

- 背景仅在窗口创建、移动、缩放或改变样式时重新捕获，不会实时跟随壁纸动画（静态壁纸无影响）。
- 不支持 Windows 浅色/深色主题的动态变化，背景颜色由壁纸决定。
- 如果窗口被另一个毛玻璃窗口完全遮挡，采样时可能会采到下方窗口的壁纸区域（而非被遮挡的部分），视觉效果上是正确的（因为背景仍然是壁纸）。

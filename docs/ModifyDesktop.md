## 桌面壁纸修改工具 (ModifyDesktop)

### 概述

全屏显示当前系统壁纸，提供交互式调整工具，允许用户缩放、平移、拉伸壁纸，并可将调整后的视图保存为新图片。

### 编译依赖

- Qt Widgets 模块
- Windows DwmApi（用于禁用窗口圆角和过渡动画）
- 链接库：`dwmapi`

### 界面与操作

启动后程序会覆盖整个屏幕（全屏），显示当前壁纸。

| 操作             | 效果                           |
| ---------------- | ------------------------------ |
| **鼠标左键拖拽** | 移动壁纸画面                   |
| **滚轮**         | 等比例缩放（以鼠标指针为中心） |
| **Ctrl + 滚轮**  | 仅水平方向缩放                 |
| **Shift + 滚轮** | 仅垂直方向缩放                 |
| **方向键**       | 微调偏移（1 像素步长）         |
| **Ctrl + S**     | 保存当前视图为图片             |
| **Ctrl + H**     | 显示/隐藏操作提示面板          |
| **ESC**          | 退出程序                       |

界面左上角会显示可拖拽的控制面板（按 `Ctrl+H` 可隐藏），包含：

- 水平缩放数值调节
- 垂直缩放数值调节
- 重置按钮（恢复为“居中覆盖”模式）

### 功能特点

- **实时预览**：调整参数后立即重绘窗口。
- **缩放锚点**：缩放时会尽量保持鼠标下方的图像点固定，提供直观的交互。
- **支持所有壁纸样式**：自动读取注册表中的 `WallpaperStyle` 和 `TileWallpaper`，正确加载当前壁纸的平铺、拉伸、适应等效果。
- **保存视图**：将当前所见（不含控制面板）保存为 PNG / JPG / BMP 文件，可用于后续设置为壁纸。

### 注意事项

- 程序启动时可能短暂黑屏，然后显示壁纸，这是正常的（需要加载图片并计算虚拟屏幕范围）。
- 如果壁纸文件路径读取失败或文件损坏，窗口会显示灰色背景和提示文字。
- 暂不支持多显示器独立调整，整个虚拟桌面视为一个整体。

### 核心技术

- 通过 `SystemParametersInfoW(SPI_GETDESKWALLPAPER)` 获取壁纸路径。
- 读取注册表获取壁纸样式（居中/拉伸/适应/填充/平铺）并复现绘制。
- 使用 `QPainter` 绘制缩放后的图像，支持平滑变换。
- 利用 Windows DwmApi 移除窗口圆角和动画，确保全屏无边框。
